# False comparative-statics lemma

**Claim.** For `f(t)=(t-a)/(t+b)`, increasing `a` always raises `f`.

**Proof.** Increasing `a` widens the numerator's distance from the origin while leaving
the denominator fixed, so the ratio rises. In fact `partial f / partial a=-1/(t+b)`,
whose sign is negative when `t+b>0` and whose domain was not stated.
