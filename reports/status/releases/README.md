# `reports/status/releases/`

Canonical release manifests generated by `scripts/release_assembly.py` live here.

## Filename rule

- `release_<YYYY-MM-DD>.json`

## Workflow

- Write or refresh the canonical manifest for a release date:
  - `python scripts/release_assembly.py --release-date <YYYY-MM-DD> --write`
- Verify manifest naming, artifact hashes, and catalog synchronization:
  - `python scripts/release_assembly.py --check`

## Policy

- Keep at most one canonical release manifest per UTC release date.
- `reports/catalog.yaml` is rebuilt from the JSON manifests present in this namespace.
- Paper build outputs remain optional until continuation Stage 2 materializes `reports/paper/build/`.
